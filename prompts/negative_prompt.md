# negative_prompt.md — things to never do (placeholder)

Constraints observed by this project:

- No distorted/warped facial features, no face swapping.
- No unrelated objects inserted into a photo.
- No degradation of the original photo quality for any purpose.
- No garbled / random text output.
- No change to the identity of a real building or scene.
- No uploading photos, no training, no network calls, no API keys.

If a future local styling pass is added, these rules are mandatory, not
advisory.
